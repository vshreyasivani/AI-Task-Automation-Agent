# AI Task Automation Agent

This project is a command-line based AI task automation tool that takes natural language instructions from the user and converts them into executable plans. It automates repetitive or structured tasks by generating shell commands and managing file operations.

## Project Overview

The agent performs the following steps:
- Accepts a task description in natural language
- Generates a structured plan with commands and file modifications
- Executes the plan upon user confirmation
- Accepts feedback if the task fails and regenerates an improved plan based on that feedback

The goal is to simplify automation for end-users by reducing the need for manual command-line work or scripting.

## Key Features

- Natural language task understanding
- Command generation and execution
- File creation and modification
- Feedback-based task refinement
- Safe mode for controlled execution

## Technologies Used

- Python
- Click (for CLI interface)
